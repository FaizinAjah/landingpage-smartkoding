<?php

namespace App\Http\Controllers;

use App\Models\Order;
use Illuminate\Http\Request;

class OrderController extends Controller
{
    // Sistem Checkout POS & API Pembayaran
    public function checkout(Request $req)
    {
        $order = Order::create([
            'invoice'    => 'INV-' . time(),
            'total'      => $req->total,
            'status'     => 'PAID',
            'method'     => 'QRIS_INSTANT',
            'student_id' => 101
        ]);

        return response()->json([
            'status'  => 200,
            'message' => 'Transaksi Berhasil Diverifikasi',
            'data'    => $order
        ]);
    }
}
✓ Unit Test Passed: 14 tests, 28 assertions Laravel 11.4 • PHP 8.3

TANYA JAWAB UMUM

Pertanyaan Sering Diajukan

Punya pertanyaan seputar kelas Pemrograman Web Tingkat Lanjut? Cek jawaban di bawah ini.

Apakah pemula yang belum pernah belajar Laravel bisa ikut?
Bisa! Di 3 minggu awal kita mengulang kembali fondasi logika PHP 8 modern dan konsep Object Oriented Programming (OOP). Jika kamu memiliki sedikit pemahaman dasar HTML atau PHP dasar, kamu akan sangat nyaman mengikuti kurikulum ini.
Apakah kelas ini diadakan tatap muka offline atau online?
Program Web Tingkat Lanjut tersedia dalam dua format yang bisa kamu pilih: tatap muka langsung di Lab Komputer Pasuruan dengan PC spek tinggi disediakan, ATAU format online live review melalui Google Meet/Zoom dan Discord VIP jika kamu berdomisili di luar Pasuruan.
Apakah saya mendapatkan sertifikat setelah selesai?
Ya. Setiap siswa yang menyelesaikan tugas praktikum dan Capstone Project POS akan memperoleh E-Sertifikat Kelulusan resmi berstandar kompetensi industri yang bisa diverifikasi secara digital dan dilampirkan di profil LinkedIn atau CV kerja.
Bagaimana jika saya berhalangan hadir di suatu sesi?
Tenang! Semua sesi dilengkapi rangkuman materi terstruktur, repositori kode langkah-demi-langkah di GitHub, dan rekaman video yang bisa dipelajari ulang kapan saja tanpa batas waktu.
